We design consensus-building for the AI era.

- **[Cartographer (Baisoku Kaigi)](https://baisoku-kaigi.com/en)**: Plural Reality's AI tool for the moment before people deliberate. Each participant puts their own views into words, and the group sees where it agrees and where it is divided. Featured in DemocracyNext's paper [Deliberative Muscles & AI](https://www.demnext.org/action/deliberative-muscles-and-ai).
- **[Baisoku Survey](https://baisoku-survey.plural-reality.com/lp)**: AI-driven surveys that ask follow-up questions based on each answer.
